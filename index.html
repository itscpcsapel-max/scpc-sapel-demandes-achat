⚠ Configuration requise — Lisez ceci avant de deployer

  1. Allez sur portal.azure.com > Azure Active Directory > App registrations > New registration
  2. Nom : SCPC SAPEL Demandes Achat  |  Supported account types : Single tenant
  3. Redirect URI : Single-page application (SPA) puis entrez l'URL de cette page
  4. Apres creation, copiez Application (client) ID et Directory (tenant) ID
  5. Allez dans API permissions et ajoutez : User.Read, Sites.ReadWrite.All, Mail.Send (Microsoft Graph)
  6. Remplacez VOTRE_CLIENT_ID et VOTRE_TENANT_ID dans le code JavaScript de ce fichier
